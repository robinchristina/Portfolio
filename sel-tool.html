Why I built this

During my five years as a school counselor, I used feelings wheels constantly — printed on paper, laminated, stuck to clipboards. They're one of the most effective tools in an elementary counselor's kit because they give kids language for experiences they can feel but can't name yet.

I built this digital version to demonstrate what's possible when someone who has actually used these tools in a counseling session is also the person writing the code.

How it was built

Built entirely with vanilla JavaScript and SVG — no frameworks, no libraries. Each slice is rendered mathematically using polar coordinates, and the coping strategies are drawn from evidence-based SEL practices I used with real students.

  • Vanilla JavaScript (ES6+)
  • SVG path rendering with polar coordinates
  • Evidence-based SEL coping strategies
  • Body-awareness language for K–5
  • CASEL-aligned emotion categories
